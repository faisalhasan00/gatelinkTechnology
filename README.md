# GateLink Technologies

> **We Build. We Automate. We Transform.**  
> *From Thoughts to Implementation.*

Modern, high-performance web experience built for **GateLink Technologies** featuring interactive 3D typography, authentic GSAP scroll-triggered choreography, perspective tilts, and dynamic crossfading industry showcases.

## Tech Stack

- **Framework**: React 19 + Vite
- **Animations**: GSAP (GreenSock) + ScrollTrigger
- **Styling**: Vanilla CSS (Tailored Design System, Dark Mode Aesthetics, Glassmorphism)
- **Icons**: Lucide React

## Getting Started

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

## Features

- **Dynamic Statement Section**: Scrub-synced character-by-character GSAP animation.
- **Interactive Selected Works**: Horizontal scroll track with 3D perspective tilt and specular glare physics.
- **Featured Insights**: Curved red laser beam SVG and interactive card hover particle effects.
- **Synchronized Industries Showcase**: Multi-column scroll-pinned crossfades with live category tracking.
- **Contact & Headquarters**: Vasavi Sky City, Gachibowli, Hyderabad.
